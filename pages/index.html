Find the demand before it becomes a contract.

Moey collects advertised work, writes down where every row came from, and drafts the CV, letter and email only from facts it can point at. When something is missing, it says so instead of inventing it.

Open the app Read the repository

Why this page is only a front door

GitHub Pages serves files and nothing else. Moey needs a database for opportunities, a server route for drafting, and a sign-in so one account cannot read another's rows — so the working app runs on a Worker, and this page points at it. Publishing the interface alone here would give you a page where every data call fails, which is worse than a page that says what it is.

Install it as an app

  • Open the app, then Chrome or Edge: use the install icon in the address bar, or ⋮ → Install Moey.
  • Safari on macOS: Share → Add to Dock.
  • It runs in its own window. The service worker keeps the shell available offline and never caches /api/*, because a stale opportunity that looks live is the thing this product exists to avoid.

What it will not do

  • Invent an employer, date, metric or contact address.
  • Send anything. Drafts open in your own mail client; you press send.
  • Claim a requirement it cannot evidence — that becomes a gap you can read.

The linked build is the preview environment. Its data is separate from any production deployment.
